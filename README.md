# Haozhe Zhang Personal Website

Personal website and online resume for Haozhe Zhang, hosted with GitHub Pages.

## Structure

- `index.html`: homepage and professional overview
- `pages/about.html`: background, education and strengths
- `pages/skills.html`: technical skill matrix
- `pages/projects.html`: project case studies
- `pages/resume.html`: interview-oriented online resume with print support
- `pages/contact.html`: contact and career direction
- `assets/css/site.css`: shared responsive design system
- `assets/js/site.js`: navigation, print and email copy interactions

## Deployment

This is a static GitHub Pages site. Push to `main` and GitHub Pages serves the site from the repository root.
